# Questionnaire-confirmed V22 smoking correction (V28)

Official source: CHARLS Followup Questionnaire 2015, printed page 70, PDF page 76 (zero indexed 75): https://charls.charlsdata.com/Public/ashelf/public/uploads/document/2015-charls-wave4/application/CHARLS_2015_Questionnaire.pdf

- `DA059`: ever used tobacco, 1=Yes, 2=No; **not** current smoking.
- `ZDA059`: prior-wave ever-smoking, determines skip route, not current status.
- `DA061_W3`: smoking status **at last interview**, not 2015 current status.
- `DA061`: smoking status **now**, 1=still smoking/current, 2=quit/former, 3=never.
- Classify using `DA061` first; when `DA061` is structurally missing and `DA059=2`, classify never; otherwise unknown. Explicit contradiction `DA059=2` with `DA061=1 or 2` -> unknown.

Only current-smoking coding changed; cohort remains 676/145 but 2015 smoking covariate counts and main estimates changed. The V22 manuscripts and responses contain outdated statistical outputs. All downstream tables, figures and replies must be regenerated and reviewed before submission. Historical diagnosis and age rules still have separate unresolved methodological issues.

No source microdata is included. `V28_smoking_transition.csv` is aggregate-only.
