# Data access

Obtain CHARLS 2015 and 2020 original archives through https://charls.pku.edu.cn/en/ under applicable data-use terms. Place CHARLS2015r.zip and CHARLS2020r.zip in a private local directory. Do NOT commit raw archives, any .dta records, participant IDs, or individual-level analysis extracts. This repository includes program source code and aggregate results only.
